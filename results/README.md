# Results

This folder contains the generated images produced by the GAN models used in this project.

## DCGAN

Contains synthetic images generated using the Deep Convolutional Generative Adversarial Network (DCGAN).

## CycleGAN

Contains images generated using CycleGAN for image-to-image translation.

## Results

The generated images are provided to visualize the performance and quality of the different GAN models.
